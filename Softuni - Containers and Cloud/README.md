## About the course:

## The main goal of the "Containers and Cloud" course is to introduce students to the best practices for creating containers with Docker and their subsequent deployment on Cloud infrastructure. The necessary Linux Shell commands will be covered, participants will learn how to work with Docker Compose to create containers. It will be examined in detail what Cloud infrastructure is and how it can be managed with code. After this course, students will be able to work comfortably with containers in a Cloud environment.

## Skills you will acquire:

### Working with the Linux Shell

### Setting up Docker containers

### Working with Docker Compose

### Deployment of a finished project in cloud infrastructure

### Preparing infrastructure by writing code

### Working with monitoring tools
