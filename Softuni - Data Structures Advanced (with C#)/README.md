## About the course:

### The Advanced Data Structures course introduces participants to the implementation of balanced trees (2-3 trees), AVL trees, red-black and AA trees. They will learn to work with hash tables, sets and associative arrays, as well as implement hashing algorithms and how to deal with collisions. Working with data structures helps to better organize information, as well as to improve the quality of program execution. They are also of great importance in the construction of a number of algorithms. As additional knowledge, students will also learn how to build on various data structures in order to optimize the solution of specific problems. 

## Skills you will acquire:

### Implementation of balanced trees

### Working with red - black trees

### Working with AVL trees and rotations

### Implementing hash tables and hashing algorithms

### Working with and dealing with collisions

### Upgrading and modifying data structures
