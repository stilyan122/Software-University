## About the course:

## In the "ASP.NET Fundamentals" course, students will lay the foundations of important principles embedded in ASP.NET. They will be introduced to the basic principles of web development, such as HTTP protocols, sessions and cookies, as well as asynchronous processing. They will learn about the MVC pattern by creating their own web applications that support all the basic functionalities that are needed for a modern web application. They will look at the application of C# and relational databases in creating such an application, using MS SQL Server with separation of models, views and controllers for these purposes. They will learn the basics of authentication in order to acquire skills for dealing with users of web applications. 

## Skills you will acquire:

### Getting to know the basics of ASP.NET

### Using databases in ASP.NET

### Working with the HTTP protocol

### Working with cookies and sessions

### Working with the MVC pattern

### Working with built-in authentication

### Working with asynchronous processing
