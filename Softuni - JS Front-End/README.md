## About the course:

### In the "JS Front-End" course, basic knowledge of the JavaScript language will be obtained, such as the basics of syntax, working with arrays, matrices, objects, classes and writing functions. The course will develop algorithmic thinking. After successfully completing this course, you will be able to work with the DOM tree, manipulate it and work with "events". Functional and OOP approaches to JavaScript programming will be covered. HTTP and REST data transfer concepts will be studied.

## Skills you will acquire:

### Knowledge of basic JavaScript syntax

### Working with classes and objects

### Working with functions and expressions

### Working with linear structures

### Information extraction and manipulation of the DOM tree

### Working with HTTP and REST
